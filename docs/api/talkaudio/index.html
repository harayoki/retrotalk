TalkAudio

Extends: SimpleAudio

RetroTalk の入口です。読み込むと MmsxxRetroTalk という名前で使えます。

音声の登録と再生を扱います。SimpleAudio を継承しているので、 音量と消音の操作もここから行えます。

Example

CODE
const voice = new MmsxxRetroTalk(new AudioContext());
voice.talk('コンニチワ');

Constructor

new TalkAudio(ctx: AudioContext, opts?: object): TalkAudio

Parameters

  • ctx (AudioContext) — 呼び出し側で作った AudioContext
  • opts (object, optional)
    • opts.maxVoices (number, optional, default: 8) — 同時に再生できる音の数
    • opts.maxTalk (number, optional, default: 1) — 同時に再生できるセリフの数

Instance Methods

defineTalk(name: string, text: string, opts?: object): void

テキストに名前を付けて登録します。再生はしません。

同じテキストを何度も再生するときに使います。作った波形は名前ごとに 保持するので、2 回目以降は作り直しません。

@ で始まる指示をテキストに混ぜられます。指示はそこから後ろに効きます。

@p<Hz> 声の高さ。例 @p200 @s<%> 話す速さ。例 @s150（1.5 倍） @v<0-15> 音量。例 @v8

CODE
voice.defineTalk('two', 'ワタシデス。@p180 イエ、ワタシデス。');

抑揚は句読点（、 。）で元に戻ります。文全体で少しずつ下がるため、 切れ目が無いと長い文の終わりで音が沈みます。空白では戻りません。

Parameters

  • name (string) — 登録名
  • text (string) — カタカナ。空白と句読点は間になります
  • opts (object, optional) — 音声のパラメータ。一覧は renderTalk() の説明にあります。 unknown は読めない文字が混ざったときの扱いで、 warn（初期値）/ error / ignore から選びます

Returns

  • void

talk( text: string, opts?: object, priority?: number, ): number | undefined

テキストをその場で再生します。

defineTalk() と playTalk() をまとめて行う短い書き方です。

CODE
voice.talk('コンニチワ');

登録は残らないので、作った波形も保持しません。同じテキストを 繰り返し再生するなら defineTalk() で名前を付けてください。

Parameters

  • text (string) — カタカナ。defineTalk() と同じ
  • opts (object, optional) — 音声のパラメータ。defineTalk() と同じ
  • priority (number, optional, default: 0) — playTalk() と同じ

Returns

  • number | undefined — 再生 ID。再生できなかったときは undefined

checkTalk(text: string): Object

読み上げられない文字を調べます。再生はしません。

登録する前に確かめるときに使います。読めない文字がテキストのどこにあるかも返します。

CODE
const got = voice.checkTalk('今日は 3ガツ デス');
// { ok: false, kana: 6, unknown: [{ ch: '今', at: 0, kind: 'kanji' }, ...] }

Parameters

  • text (string) — 調べるテキスト

Returns

  • Object — ok は読めない文字が無ければ true、kana は読めた文字数、 at はテキスト内の位置、kind は文字の種別

prepareTalk(name: string | Array.<string>): void

波形の生成だけを行います。再生はしません。

playTalk() は初回に波形を生成するため、その分だけ再生の開始が遅れます。 複数を重ねて再生するとき、この遅れがずれになります。2 人分を続けて playTalk() すると、2 人目は 1 人目の生成が終わってから始まります。 先に両方を生成しておけば、ずれずに重なります。

Parameters

  • name (string | Array.<string>) — defineTalk() で登録した名前。配列で渡せます

Returns

  • void

playTalk( name: string | Array.<string>, priority?: number, opts?: object, ): number | Array.<number> | undefined

登録済みのテキストを再生します。

波形は初回に生成し、名前ごとに保持します。2 回目以降は作り直しません。 同時再生数（maxTalk）を超えると、優先度の低いものが停止します。

Parameters

  • name (string | Array.<string>) — defineTalk() で登録した名前。 配列を渡すと、すべての波形を生成してから続けて再生します
  • priority (number, optional, default: 0) — 値が大きいほど優先されます
  • opts (object, optional) — gain は音量の倍率、rate は再生速度（1 より大きいと速く高くなります）

Returns

  • number | Array.<number> | undefined — 再生 ID。配列を渡したときは配列。 再生できなかったときは undefined

forgetTalk(name?: string | Array.<string>): void

保持している波形を破棄します。

defineTalk() は名前ごとに波形を持ち続けます。作り直さずに済ませるためですが、 その分メモリを使います。使わなくなったものは破棄できます。

CODE
voice.forgetTalk('hello');              // 名前を指定して破棄
voice.forgetTalk(['demo1', 'demo2']);   // まとめて破棄
voice.forgetTalk();                     // すべて破棄

再生中のものは最後まで再生されます。波形は再生側が参照しています。

Parameters

  • name (string | Array.<string>, optional) — 登録名。省略するとすべて破棄します

Returns

  • void

再生中のものを停止します。

Parameters

  • what (string | number, optional) — 登録名、または playTalk() の戻り値。 省略するとすべて停止します

Returns

  • void

unlock()

Inherited from SimpleAudio#unlock

Overrides: SimpleAudio#unlock

再生できる状態にします。

ユーザーがページを一度操作したあとに呼びます。ブラウザの制限によるものです。 talk() と playTalk() は内部で呼ぶので、通常は呼び出す必要がありません。

AudioContext はここでは作りません。呼び出し側で作って渡してください。

CODE
const voice = new TalkAudio(new AudioContext());

ブラウザが同時に作れる AudioContext の数には上限があり、 ライブラリがそれぞれ勝手に作ると足りなくなります。

Throws

  • Error — AudioContext が渡されていないとき

checkTalk(text: string): Object

static

読める文字かどうかだけを調べます。読み上げはしません。

辞書を持っていないので漢字は読めません（数字と英字は 1 字ずつ読みます）。 parseTalk() は読めない文字を黙って飛ばすため、そのままでは 「なぜかそこだけ抜ける」ことになります。鳴らす前に確かめられるようにしてあります。

CODE
const got = checkTalk('今日は 3ガツ デス');
// { ok: false, kana: 6, unknown: [{ ch: '今', at: 0, kind: 'kanji' }, ...] }

Alias: TalkAudio.checkTalk

Parameters

  • text (string) — しゃべらせる文

Returns

  • Object — kind は kanji / other

parseTalk(text: string): Array.<object>

static

文字列を拍の並びに変換します。

波形を作る前の段です。renderTalk() が内部で呼ぶので、ふつうは直接 使いません。書いたものがどう読まれるかを確かめたいときに使えます。

CODE
const moras = parseTalk('コンニチワ、@p200 イイ テンキ デス。');

返す拍は次の値を持ちます。 c 子音（無ければ ''） v 母音（n は撥音） hold 母音を伸ばす倍率（「ー」で増える） stop 直前で詰まる（「ッ」） pause 休み（空白、読点） set 途中で変える指示（@p @s @v） tune 抑揚の高さを上げ下げする（＞ ＜。半音単位。長さは持たない） brk 文の切れ目（読点、句点）。空白には付かない mark どの記号で切れたか（. , ! ? !? …） wave 伸ばしながら揺らす（〜） pal 拗音（「キャ」のように子音が口蓋化する） tie 直前の拍と同じ音符で歌う（( ) でくくったところ） lift しゃべるときに持ち上げる（( ) でくくったところ）

Alias: TalkAudio.parseTalk

Parameters

  • text (string) — かな。ひらがなでもカタカナでもかまいません（内部で揃えます）

Returns

  • Array.<object> — 拍の並び

talkFrames( text: string, opts?: object, ): Array.<{Array.<param:number>, Array.<bpos:number>, P:number, amp:number, voiced:boolean, noise:boolean, mora:number}>

static

波形にする手前の、フレームの並びを返します。

耳で聴かずに中身を測るために使います。音になったあとではフォルマントが 読みにくいので、その前の値(param は番地で、1 番地はおよそ 95 セント)を そのまま出します。鳴らすときと同じ道を通るので、ここで見えるものが そのまま音になります。

CODE
const frames = talkFrames('キャ');

mora は parseTalk() が返した並びの添字で、「キャ」と「カ」の同じ拍を 突き合わせるのに使えます。

Alias: TalkAudio.talkFrames

Parameters

  • text (string) — カタカナ(ひらがなも可)
  • opts (object, optional) — renderTalk と同じ

Returns

  • Array.<{Array.<param:number>, Array.<bpos:number>, P:number, amp:number, voiced:boolean, noise:boolean, mora:number}>

renderTalk(text: string, opts?: object): Object

static

テキストから波形を生成します。再生はしません。

音として鳴らすときは TalkAudio が内部で呼びます。書き出したいときや、 自分で AudioBuffer を組み立てたいときに直接使います。

CODE
const { rate, data } = renderTalk('コンニチワ', { pitch: 200 });

tuneStep から下は実機に無いパラメータです。実機は男女を子音データを 使い回してピッチだけで分けていたので、声色を変える手がありませんでした。

Alias: TalkAudio.renderTalk

Parameters

  • text (string) — カタカナ(ひらがなも可)
  • opts (object, optional)
    • opts.pitch (number, optional, default: 280) — 声の高さ Hz。 周期側で丸められるので高い声ほど音程が粗くなる。 実機の男声(m)は 1 オクターブ下なので 165 あたり
    • opts.frame (number, optional, default: "0.010") — 1 フレームの長さ(秒)。実機は 10ms か 20ms。 長くすると粗くなり、同時に遅くなる(実機がそうだった)
    • opts.speed (number, optional, default: 1) — しゃべる速さ
    • opts.fall (number, optional, default: 4) — 語尾へ下がる量(半音)
    • opts.rise (number, optional, default: 1) — 出だしで上がる量(半音。実機の自動抑揚)
    • opts.interp (boolean, optional, default: false) — フレーム間を補間する(実機の S.I)。 切ると 10ms の階段が露骨に出る。ここがクセの本命
    • opts.slewF (number, optional, default: 6) — 1 フレームに動かせるフォルマントの幅。 実機の上限は 16 だが、そこまで速いと遷移が 10ms で終わり、 子音の場所が聞き取れなくなる
    • opts.slewB (number, optional, default: 4) — 同・帯域幅(実機の上限も 4)
    • opts.slewP (number, optional, default: 2) — 同・ピッチ(実機の上限は 4)
    • opts.lag (number, optional, default: 0) — しゃべり出すまでの間(秒)。 実機のあれは演出ではなく Z80 の計算時間だった
    • opts.lagPerMora (number, optional, default: 0) — 1 拍ごとに増える間(秒)
    • opts.bits (number, optional, default: 0) — 量子化ビット数(0 でしない)。 実機は 14 ビットなので、これは実機由来ではない
    • opts.tuneStep (number, optional, default: 1) — ＞ ＜ 1 つで動く量(半音)。 止まるところ(±12 半音)は変わらない
    • opts.pitchShift (number, optional, default: 0) — 文の中の @p ごと上げ下げする量(半音)。 写してきた文は高さが書き込まれているので、pitch では動かない
    • opts.volume (number, optional, default: 10) — @v を書かなかったときの音量(0〜15)
    • opts.volumeShift (number, optional, default: 0) — 文の中の @v ごと上げ下げする量(段)。 @v と同じ目盛り
    • opts.speedShift (number, optional, default: 1) — 文の中の @s ごと掛ける倍率
    • opts.formantShift (number, optional, default: 0) — 声道の長さ(番地)。 +3 で 1 割 8 分ほど高い声色。大人の男 -4 / 大人の女 +2 / 子ども +5 あたり
    • opts.bandShift (number, optional, default: 0) — 共鳴の鋭さ。+ でぼやけ、- で硬く締まる
    • opts.breath (number, optional, default: 0) — 息の混じり(0〜1)。かすれ声になる
    • opts.jitter (number, optional, default: 0) — 周期のゆらぎ(0〜1)。だみ声・年寄りの声
    • opts.assembly (object, optional) — 音の組み替え方(ASSEMBLY を上書き)。 聴き比べ用で、良かった値は既定に写す。設定のまま残さない
    • opts.format (string, optional) — 文の書き方。省くと RetroTalk の書き方。 'aquestalk' でゆっくり(AquesTalk)風の記号列として読む / 'voicevox' で VOICEVOX の .vvproj か /audio_query を読む (text に JSON か、読み込んだそのままの object を渡す)
    • opts.style (string, optional, default: "'flat'") — 一音一音の形。歌でもしゃべりでも効く。 'flat' 高さと長さだけ / 'natural' 一音ごとに少しだけ落ちる(しゃべり向け) / 'adsr' 一音ごとに立ち上がりと切りを付ける(歌向け) / 'vibrato' それに加えて、伸ばすと震えはじめる(歌向け)
    • opts.seed (number, optional, default: 1) — ノイズの種。同じ種なら同じ波形になる
    • opts.gainNorm (boolean, optional, default: true) — 音量をそろえる。RMS で揃えるので、 破裂音のある文だけ小さくなることがない
    • opts.level (number, optional, default: 0.15) — 揃えたあとの RMS

Returns

  • Object

voicevoxText(src: object | string, opts?: object): string

static

VOICEVOX の会話情報を、RetroTalk 向けのテキストに変換します。

VOICEVOX から抑揚と速度と音声を読み込めます。話者の情報は落としています。 拍ごとの高さと長さは @p と @s に、間は 、 と 。 に置き換えます。

Returns

  • string — RetroTalk の文

TALK_STYLES

static

一音一音の形。

---- なぜ要るか ----

歌わせると音符が音程を決めるので、しゃべりの抑揚が全部切れる。 そこまではよいのだが、音量まで真っ平らになるので、 音符が並んでいるだけで歌っているように聞こえない。 人は伸ばすところで音を張り、切るところで落とす。それを付ける。

歌のときだけのものではない。しゃべりにも同じ形が付けられるので、 名前を singStyle から style に変えた(2026-09-04)。

---- しゃべりに adsr を掛けてはいけない ----

掛けてみたら聞き取りづらくなった(2026-09-04)。歌は 1 音が 50 フレームあるが、しゃべりの母音は 11 フレームしかない。 歌の目盛りで立ち上がりに 6 フレーム使うと、母音の半分が上り坂になる。 母音がどれだけ開いているかを聞き取るところが削れるので、字が溶ける。

浅くした adsr も試したが、これも良くなかった(2026-09-04)。 形を薄めても、頭を抑えることに変わりはない。 そこで natural は形を持たない — 落ちていくだけにした。 頭がいちばん大きく、そこからほんの少し下がる。人の言い方はそれに近い。

---- 3 つのうちどれか ----

何が付くか
flat何も付けない。高さと長さだけ。既定はこれ
natural一音ごとに、ほんの少しだけ落ちていく。しゃべり向け
adsr一音ごとに立ち上がり・減り・保ち・切りを付ける。歌向け
vibratoadsr に加えて、伸ばしていると震えはじめる。歌向け

上に積んである。vibrato は adsr を含む — 音量が平らなまま音程だけ震えると、震えているというよりぐらついて聞こえる。

Alias: TalkAudio.TALK_STYLES
